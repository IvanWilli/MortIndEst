# WPP 2024 five-year life tables for Brazil

Brazil Country-level five-year life table values from the 2024 World
Population Prospects extract.

## Usage

``` r
lt5_wpp24_brazil
```

## Format

A `data.frame` with 29 columns:

- SortOrder, LocID, VarID, Time, SexID, AgeGrpStart, AgeGrpSpan:

  Integer identifiers and time or age fields.

- Notes, ISO3_code, ISO2_code, LocTypeName, Location, Variant, Sex,
  AgeGrp:

  Character metadata fields.

- MidPeriod, mx, qx, px, lx, dx, Lx, Sx, Tx, ex, ax:

  Numeric life table values.

## Source

United Nations World Population Prospects 2024.
